# 나만의 프롬프트 관리 프로그램 (Prompt Manager)

GenAI 미션을 하며 메모장·노션·메신저에 흩어져 있던 프롬프트를 한 곳에서 관리하는 **Python 콘솔 프로그램**입니다.
터미널에서 메뉴 번호를 입력해 프롬프트를 추가하고, 카테고리별로 모아 보고, 키워드로 검색하고, 자주 쓰는 프롬프트는 즐겨찾기로 관리할 수 있습니다.

- 외부 라이브러리 없이 Python 기본 문법만 사용합니다. (보너스 기능은 표준 라이브러리 `json`, `os` 사용)
- 데이터는 **리스트 + 딕셔너리**로 저장하며, 프로그램 실행 중에만 유지됩니다. (종료 시 초기화)
- 이전 미션에서 작성한 프롬프트 5개가 기본 데이터로 등록되어 있습니다.

## 실행 방법

**요구 사항:** Python 3.10 이상

```bash
# 1. 저장소 내려받기
git clone https://github.com/42s-joowon/aiaiai.git
cd aiaiai

# 2. Python 버전 확인
python --version        # macOS/Linux는 python3 --version

# 3. 프로그램 실행
python prompt_manager.py   # macOS/Linux는 python3 prompt_manager.py
```

VSCode에서는 `prompt_manager.py`를 연 뒤 오른쪽 위 ▶(Run Python File) 버튼을 눌러도 실행됩니다.

## 기능 목록

| 번호 | 메뉴 | 설명 |
|---|---|---|
| 1 | 프롬프트 추가 | 제목·내용·카테고리를 입력해 새 프롬프트 등록 (빈 값이면 재입력, 카테고리는 목록 선택 또는 직접 입력, 즐겨찾기 기본값 `False`) |
| 2 | 프롬프트 목록 | 전체 프롬프트를 `번호. [카테고리] 제목 ⭐` 형식으로 출력 |
| 3 | 카테고리별 조회 | 카테고리를 선택하면 해당 카테고리 프롬프트만 출력 |
| 4 | 프롬프트 검색 | 키워드가 제목 또는 내용에 포함된 프롬프트 검색 (대소문자 무시) |
| 5 | 프롬프트 상세 보기 | 번호로 선택한 프롬프트의 제목·카테고리·즐겨찾기·내용 전체 출력 |
| 6 | 즐겨찾기 관리 | 번호로 선택한 프롬프트의 즐겨찾기 추가/해제 (토글) |
| 7 | 즐겨찾기 목록 | 즐겨찾기한 프롬프트만 모아 보기 |
| 8 | 프롬프트 수정 ✨ | 제목·내용·카테고리 수정 (엔터 입력 시 기존 값 유지) |
| 9 | 프롬프트 삭제 ✨ | 확인(y/N) 후 삭제 |
| 10 | 인기 프롬프트 TOP 5 ✨ | 상세 보기 횟수(조회수) 기준 상위 5개 |
| 11 | JSON 저장 ✨ | 현재 프롬프트를 `prompts.json`으로 저장 |
| 12 | JSON 불러오기 ✨ | `prompts.json`에서 프롬프트 불러오기 |
| 13 | Markdown 내보내기 ✨ | `exports/` 폴더에 카테고리별 `.md` 파일 생성 |
| 0 | 종료 | 프로그램 종료 |

✨ 표시는 보너스 과제 기능입니다.

- 잘못된 메뉴 번호를 입력하면 안내 메시지 후 메뉴를 다시 보여줍니다.
- 모든 기능은 수행 후 메뉴로 돌아옵니다.
- 카테고리 조회·검색·즐겨찾기 결과에도 **전체 목록 기준 번호**를 표시하므로, 그 번호로 바로 상세 보기를 할 수 있습니다.

## 프롬프트 카테고리

| 카테고리 | 설명 | 기본 등록 프롬프트 |
|---|---|---|
| 텍스트 생성 | 글쓰기, 요약, 이메일 등 텍스트 결과물을 만드는 프롬프트 | 블로그 글 작성 도우미 ⭐ |
| 이미지 생성 | 이미지 생성 AI용 스타일·구도·키워드 프롬프트 | 제품 썸네일 생성 |
| 영상 생성 | 영상 스크립트, 장면 구성 등 영상 제작 프롬프트 | 광고 스크립트 작성 |
| 페르소나 | AI에게 역할·말투·답변 규칙을 부여하는 프롬프트 | IT 컨설턴트 페르소나 |
| 자동화 | 노코드 자동화 워크플로에 넣어 쓰는 정형화된 프롬프트 | 뉴스 요약 프롬프트 |
| 기타 | 위 분류에 속하지 않는 프롬프트 | - |

추가할 때 "직접 입력"을 고르면 새 카테고리를 만들 수 있고, 만든 카테고리는 이후 카테고리 목록에도 나타납니다.

## 데이터 구조

```python
prompts = [
    {
        "title": "블로그 글 작성 도우미",
        "content": "당신은 10년 경력의 전문 블로거입니다...",
        "category": "텍스트 생성",
        "favorite": True,
        "views": 0,          # 보너스: 상세 보기 횟수
    },
    ...
]
```

## 코드 구조

`prompt_manager.py` 하나에 기능별 함수로 나뉘어 있습니다.

| 구분 | 함수 |
|---|---|
| 데이터 | `create_default_prompts()` |
| 입력 도우미 | `input_required()`, `select_category()`, `input_prompt_index()`, `input_optional()` |
| 출력 도우미 | `format_prompt_line()`, `print_prompt_lines()`, `print_categories()` |
| 필수 기능 | `add_prompt()`, `show_list()`, `show_by_category()`, `search_prompt()`, `show_detail()`, `toggle_favorite()`, `show_favorites()` |
| 보너스 기능 | `edit_prompt()`, `delete_prompt()`, `show_top()`, `save_prompts()`, `load_prompts()`, `export_markdown()` |
| 메뉴 | `show_menu()`, `get_menu_items()`, `main()` |

메뉴 번호·이름·함수를 `get_menu_items()` 한 곳에서 관리하므로 새 기능을 추가할 때 이 목록에 한 줄만 추가하면 됩니다.
